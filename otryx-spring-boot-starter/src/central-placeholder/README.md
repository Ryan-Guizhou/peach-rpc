# Peach RPC Spring Boot Starter

This artifact is intentionally a dependency-only Spring Boot Starter and does not contain implementation classes.

- Runtime auto-configuration: `peach-rpc-spring-boot-autoconfigure`
- Source repository: https://github.com/Ryan-Guizhou/peach-rpc
- Documentation: https://github.com/Ryan-Guizhou/peach-rpc#readme

The `sources` and `javadoc` classifiers for this module contain this placeholder document so the dependency-only Starter satisfies Maven Central publication requirements without exposing artificial public API types.
